# IPTV Player لـ Android TV

تطبيق Kotlin يقرأ قوائم IPTV (روابط M3U/M3U8 أو بيانات Xtream Codes) ويشغّل القنوات على Android TV باستخدام ExoPlayer (Media3).

## المميزات
- إضافة سيرفر برابط M3U أو ببيانات Xtream (السيرفر + المستخدم + كلمة المرور).
- حفظ آخر سيرفر وتحميله تلقائياً عند فتح التطبيق.
- عرض القنوات مع الشعارات، بحث، وتصفية حسب التصنيف.
- تحكم كامل بالريموت: أسهم للتنقل، OK للتشغيل.
- داخل المشغّل: السهم لأعلى/أسفل (أو CH+/CH-) لتغيير القناة، OK لإظهار اسم القناة، Back للرجوع.
- يدعم HLS و TS وMP4 مع إعادة توجيه HTTP→HTTPS.

## طريقة البناء
1. افتح مجلد المشروع في Android Studio (Koala أو أحدث) ودع Gradle يعمل Sync.
2. ثبّت APK على التلفاز: `Build > Build APK(s)` ثم انقله بـ USB أو `adb install app-debug.apk`.
   - للـ adb: فعّل Developer options و Network debugging في التلفاز ثم `adb connect <TV_IP>`.
3. شغّل التطبيق من قائمة التطبيقات، اضغط "إضافة سيرفر" وأدخل الرابط.

## الأفلام والمسلسلات
- تعمل عبر Xtream Codes API، ولذلك تحتاج سيرفراً من هذا النوع: إما بإدخال (السيرفر + المستخدم + كلمة المرور)، أو برابط M3U من نوع `get.php?username=..&password=..` (تُستخرج منه البيانات تلقائياً).
- أزرار «مباشر / الأفلام / المسلسلات» في أعلى الشاشة، ويُحمَّل كل قسم عند أول فتح ثم يُحفظ مؤقتاً.
- المسلسل: اختره لتفتح شاشة المواسم والحلقات، والحلقة التالية تعمل تلقائياً عند انتهاء الحالية.
- داخل مشغّل الأفلام: ← / → تأخير وتقديم 10 ثوانٍ (30 مع الضغط المطوّل)، OK إيقاف/تشغيل.

## المفضلة والسجل وأدوات الريموت
- **المفضلة:** اضغط مطولاً على OK فوق أي قناة أو فيلم أو مسلسل لإضافته أو إزالته (تظهر ★).
- **الأخيرة:** آخر 40 عنصراً شاهدتها.
- **رقم القناة:** اكتب رقماً من الريموت أثناء المشاهدة (مثل 12) فيقفز إلى القناة رقم 12 في القائمة.
- **القائمة السريعة:** في البث المباشر اضغط OK أو السهم الأيسر لعرض قائمة القنوات فوق الفيديو، وBack لإغلاقها.
- القنوات التي ليس لها شعار يظهر لها حرف بدل الصورة.

## ملف الإعدادات البعيد (تحديث السيرفر تلقائياً)
1. انسخ `config-example.json` واكتب فيه بيانات سيرفرك، ثم ارفعه على رابط يمكن للتطبيق قراءته (مثل GitHub Gist الخاص/Raw أو موقعك).
2. في التطبيق: «إضافة سيرفر» ← «ملف إعدادات» ← الصق الرابط ← حفظ.
3. من الآن يقرأ التطبيق الملف عند كل تشغيل ويحدّث السيرفر إذا تغيّر، وإن لم يتوفر الإنترنت يستخدم آخر سيرفر محفوظ.
4. لدمج الرابط من أول تشغيل ضعه في `DEFAULT_CONFIG_URL` داخل `SourceStore.kt`.
- صيغة M3U: `{"type":"m3u","url":"http://.../list.m3u"}`.
- استعمل رابطاً طويلاً غير معلن، فكل من يعرف الرابط يرى بيانات الدخول.

## بنية الكود
- `RemoteConfig.kt` — قراءة ملف الإعدادات.
- `UserLists.kt` — المفضلة والسجل.
- `XtreamApi.kt` — جلب الأفلام والمسلسلات والحلقات.
- `SeriesActivity.kt` — شاشة حلقات المسلسل.
- `M3uParser.kt` — تحليل ملفات M3U.
- `PlaylistLoader.kt` — تحميل القائمة من الشبكة.
- `SourceStore.kt` — حفظ السيرفر وتحويل Xtream إلى رابط M3U.
- `MainActivity.kt` / `ChannelAdapter.kt` — واجهة القنوات.
- `PlayerActivity.kt` — المشغّل.
